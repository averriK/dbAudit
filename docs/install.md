# Install

dbAudit ships OS-specific installers.

- macOS / Linux: [macOS / Linux install]({{ "/docs/macos/" | relative_url }})
- Windows: [Windows install]({{ "/docs/windows/" | relative_url }})

## Installers

- macOS/Linux: `install/install.sh` (installs under `/usr/local`)
- Windows: `install/install.ps1` (installs under `%LOCALAPPDATA%` and adds user shims to PATH)
